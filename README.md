# Lernmaster
LernMaster ist die ideale Lern- und Organisationsplattform für Berufslehre, Gymnasium und Weiterbildung in der Schweiz.  Sie vereint einen interaktiven Lernkalender, Stundenplan, digitale Karteikarten mit Quiz-Modus, Zusammenfassungen, einen Pomodoro-Timer, den Schweizer Notenrechner sowie Study- und Post-Rooms für den perfekten Austausch.
